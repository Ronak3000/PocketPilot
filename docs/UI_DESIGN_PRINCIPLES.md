# UI Design Principles

The frontend must feel:
- Sleek
- Modern
- Premium
- Calm
- Trustworthy
- Financially precise
- Spacious
- Responsive
- Production-quality

## Visual References
Product quality and restraint of: Linear, Arc, ChatGPT, Stripe, Apple Wallet, Premium native finance applications.

## Anti-patterns
It must not look like:
- A generic admin dashboard
- A template marketplace dashboard
- A crypto trading screen
- A cluttered banking portal
- A terminal
- A neon AI product
- A hackathon prototype
- A collection of unrelated cards

## Design Principles
- The chat is the primary workspace.
- Future Receipt is the signature component.
- The interface should minimize steps.
- Use strong hierarchy and generous spacing.
- Use motion only when it improves comprehension.
- Avoid excessive glassmorphism.
- Avoid excessive gradients.
- Avoid crowded sidebars.
- Avoid fake financial charts.
- Mobile behavior must be intentionally designed.
- Accessibility and keyboard navigation matter.
