# PocketPilot Product Overview

PocketPilot is a pre-spend financial decision companion.
It allows a user to ask questions such as:
> "Can I afford this ₹59,999 phone on a 12-month EMI?"

The product then:
- Collects the user's financial context.
- Extracts the proposed purchase details.
- Runs deterministic cash-flow calculations.
- Tests the purchase against the user's Money Constitution.
- Generates multiple possible futures.
- Shows a Future Receipt explaining the impact.
- Suggests a safer purchase plan.
